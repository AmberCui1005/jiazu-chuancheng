# 家族树传承 · 一脉

《一脉 · 家国传承录》的可玩演示版。架空王朝「大岐」，皇族萧氏，家族树即棋盘。

## 玩法

- 每年一道国策（三选一），另可立储、赐婚各一次，点国策卡即结算该年。
- 五维：文、武、德、体、貌。体决定寿数与病亡风险，也决定生育；貌决定初始好感度、婚配档次与求婚成功率；谋已并入文（支持度中文按 1.2 折算）。
- 死因三类：寿终正寝 / 病亡 / 死于非命（谋杀、意外、兵变），判定顺序固定。
- 国势四条会归零的线（皇权、民心、武备、国库）加一条不归零的声望；宗室在册归零即祚终。
- 家主去世后按支持度传位；支持度低于 30 走继承危机，成为分裂结局。
- 结局：废立 / 民变 / 外寇 / 财竭 / 祚终 / 分裂 / 三十年存续。

## 运行

直接用浏览器打开 `index.html`，无依赖、无构建。

## 数值来源

全部公式取自《一脉·家国传承录-完整设计文档 v1.2》：

- 支持度 = 1.6×(1.2×文+武+德) + 2×(貌−3) + 关系 + 嫡庶 + 长幼 + 派系 + 立储
- 五维遗传 = 3 + 0.6×(父母该项均值−3) ± 1.2，单维夹 1–5，单人总和上限 16
- 岁入 = (600+400×民心/100)×(0.85+0.15×皇权/100)；岁支 = 120+2.6×武备+150+8×宗室+70+利息
- 生育 = 0.35 × 年龄系数 × 夫妻体质均值系数 ×（1−0.15×现存子女数）
- 死亡顺序：死于非命 → 病亡 → 寿终正寝（寿数 = 38+4×体质±6）
